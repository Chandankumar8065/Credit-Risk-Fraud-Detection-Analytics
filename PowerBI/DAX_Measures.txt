# Credit Risk & Fraud Detection — DAX Measures

These measures are designed for the compact, pre-aggregated summary tables generated by [build_powerbi_summaries.py](../Python/build_powerbi_summaries.py). Create each measure in Power BI using Modeling > New measure.

## Customer profile

```DAX
Total Customers = SUM('01_customer_profile_summary'[customers])

Average Customer Age =
DIVIDE(
    SUMX('01_customer_profile_summary',
        '01_customer_profile_summary'[avg_age]
            * '01_customer_profile_summary'[customers]),
    [Total Customers]
)

Average Annual Income =
DIVIDE(
    SUMX('01_customer_profile_summary',
        '01_customer_profile_summary'[avg_annual_income_inr]
            * '01_customer_profile_summary'[customers]),
    [Total Customers]
)
```

## Applications

```DAX
Total Applications = SUM('06_application_summary'[applications])

Average Requested Amount =
DIVIDE(
    SUMX('06_application_summary',
        '06_application_summary'[avg_requested_amount_inr]
            * '06_application_summary'[applications]),
    [Total Applications]
)
```

## Loans

```DAX
Total Loans = SUM('02_loan_type_summary'[total_loans])
Total Defaults = SUM('02_loan_type_summary'[defaults])
Total Principal = SUM('02_loan_type_summary'[total_principal_inr])
Default Rate = DIVIDE([Total Defaults], [Total Loans], 0)

Average Interest Rate =
DIVIDE(
    SUMX('02_loan_type_summary',
        '02_loan_type_summary'[avg_interest_rate_pct]
            * '02_loan_type_summary'[total_loans]),
    [Total Loans]
)
```

## Fraud

```DAX
Total Transactions = SUM('07_fraud_channel_type_merchant'[transactions])
Fraud Transactions = SUM('07_fraud_channel_type_merchant'[fraud_transactions])
Fraud Rate = DIVIDE([Fraud Transactions], [Total Transactions], 0)
Transaction Value = SUM('07_fraud_channel_type_merchant'[transaction_value_inr])
Average Transaction Value = DIVIDE([Transaction Value], [Total Transactions], 0)
```

## Repayments

```DAX
Total Installments = SUM('11_repayment_status_summary'[installments])
Scheduled Amount = SUM('11_repayment_status_summary'[scheduled_amount_inr])
Paid Amount = SUM('11_repayment_status_summary'[paid_amount_inr])
Payment Shortfall = [Scheduled Amount] - [Paid Amount]
Collection Rate = DIVIDE([Paid Amount], [Scheduled Amount], 0)
```

## Calculation notes

- Average age, income, requested amount and interest rate use weighted calculations. The group averages are multiplied by their group counts before division by the overall count.
- Ratios use aggregated numerators divided by aggregated denominators; do not average pre-calculated rates.
- These measures assume the summary tables retain the count and average columns named above. Do not sum average values.
- The generated summary tables are independent aggregates. Do not create relationships between them unless you deliberately add shared dimension tables.
