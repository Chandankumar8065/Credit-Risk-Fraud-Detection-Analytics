# Power BI Reports

The project includes three credit-risk/fraud Power BI reports in the current handoff:

- Loan Default Analysis
- Fraud Detection Analysis
- Loan Repayment Analysis

The PBIX files were supplied separately and are not yet stored in this GitHub repository. The screenshots supplied for preview are also pending binary upload.

A fourth screenshot supplied in the handoff is titled **Customer Churn Analysis**. It belongs to a separate project and is intentionally not presented as a Credit Risk & Fraud dashboard.

## Lightweight reporting

The project was designed around aggregated summary tables for dashboard development to reduce the memory burden of loading all 1.25 million source records into Power BI on a low-memory computer.

See the root README and [Data Validation Report](../Documentation/Data_Validation.md) for data scale and checks.
