# Python Analysis

The source notebook supplied for this project is a Jupyter notebook covering data loading, data-quality checks, relationship validation, range/date checks, repayment analysis, and exploratory analysis.

The original notebook is being prepared for publication with repository-relative paths. Place the extracted five CSV files in `../datasets/original/credit_risk_fraud_1_25m/` before running it. For a memory-constrained computer, load only the columns needed for a section or use chunked CSV reading for transaction and repayment analysis.

**Reproducibility note:** the analysis was developed in Google Colab. A notebook path that refers to a personal Google Drive location must be replaced with the repository-relative data folder before running locally.
